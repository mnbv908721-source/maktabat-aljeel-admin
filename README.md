# مكتبة الجيل — لوحة الإدارة التجريبية

واجهة عربية RTL متجاوبة بصفحات الرئيسية، المنتجات، الطلبات، العملاء، والإعدادات. تعمل بدون قاعدة بيانات أو تسجيل دخول حقيقي. البيانات وهمية ومحفوظة في المتصفح، والمرفقات محلية في IndexedDB.

هذه نسخة ثابتة جاهزة لـ GitHub Pages. ملفات مكتبة jsPDF وخط Amiri بجانب index.html، وتراخيصهما مرفقة. النماذج المشتركة موجودة في models.ts. جميع الأرقام والطلبات والمستخدمين بيانات توضيحية فقط؛ ليست لوحة إدارة إنتاجية محمية.

المزامنة المحلية مع واجهة الزبون تتطلب أن تستخدم الواجهتان state.js المحدثة بنفس المتصفح وعلى نفس المصدر. لا توجد مزامنة بين أجهزة مختلفة أو ربط Convex أو دفع فعلي.
